# files/images

Сюда кладутся картинки, которые роль `static` заливает на сервер в `/var/www/images`.

В репозитории лежат 3 SVG-сэмпла, чтобы тест работал из коробки (`docker compose up`
→ плейбук → на `/images` сразу видна структура и файлы открываются).

Чтобы залить **реальную подборку из задания** (Google Drive):

```bash
pip install gdown
./scripts/download_images.sh
```

Скрипт скачает архив, распакует картинки в эту папку, и следующий прогон плейбука
разложит их на сервер. SVG-сэмплы можно удалить.
